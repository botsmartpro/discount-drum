# Новогодний барабан скидок

Статическая демо-игра на русском языке. Для локального запуска откройте `index.html` или обслужите эту папку через обычный HTTP-сервер. Сборка и зависимости не требуются. История и полученные демо-промокоды хранятся в текущем браузере. Таймер отсчитывает время до 1 января по Москве.

## GitHub Pages

Поместите содержимое папки в корень ветки `main` репозитория `botsmartpro/discount-drum`. В Settings → Pages выберите Deploy from a branch, затем ветку `main` и папку `/ (root)`. После успешного развёртывания адрес проекта — https://botsmartpro.github.io/discount-drum/.

Все скидки, промокоды и предложения партнёров демонстрационные. Коды не действуют при покупке.
